# Глоссарий и правила перевода

Исходный язык игры — английский (полные таблицы Unity Localization есть только для `en`; `fi` — частичный перевод меню).
Финские слова и вставки в английском тексте остаются как в оригинале.

## Необязательная кириллица для имён и названий

Настройки General → CyrillicPeopleNames и General → CyrillicBrandNames (по умолчанию включены) заменяют на экране
латинские имена из `translations/names-people.json` и названия из `translations/names-brands.json`. Перевод строк остаётся
прежним: имена подставляются поверх него, поэтому в обоих словарях — несклоняемые формы.

- Имена людей заносятся по частям (имя, фамилия, прозвище), чтобы работали любые сочетания: Arvo → Арво, Kirkastaja → Киркастая.
  Целиком — только имена с титулом: Mr. Duck → Мистер Дак, Dr. Pena MD → Доктор Пена.
- Финские имена — по финско-русской практической транскрипции: y → ю, ä → я, ö → ё, j → й, l перед согласной → ль;
  долгие гласные и двойные согласные сохраняются (Kurahaara → Курахаара, Jarkko → Яркко, Hyvinkää → Хювинкяя).
- Шведские и норвежские — по скандинавской: sk, stj, tj перед мягкими гласными → ш, k перед ö → ч, å → о
  (Sköldgangster → Шёльдгангстер, Kött → Чётт, Sågspånberg → Согспонберг). Английские — по устоявшимся формам (Seamus → Шеймус).
- Места (города, острова, улицы), пародии на настоящие марки, иностранные названия, газеты, фильмы и группы — транскрипцией:
  Stalburg Steel → Сталбург Стил, Market Road → Маркет-Роуд, Moca-Cola → Мока-Кола.
  Магазины, службы, компании, банды и прозвища, чьё английское название понятно по смыслу, — по-русски в кавычках:
  One Stop Shop → «Всё в одном», Open Sewer Power Company / OS Power → «Клоакэнерго», Open Homes → «Открытые дома»,
  OS Mining Services → «ОС Горснаб», Swamp Publishing → «Болото-Пресс», Rob-In Build & Repair → «Роб-Ин Стройремонт»,
  Sewerview Inn → «Клоачный вид», Devil's Angels → «Ангелы дьявола», Redemption → «Искупление»
  (Redemption Militia — ополчение «Искупление»: благотворительная организация вроде «Армии спасения», не милиция),
  Stalburg Underground → «Сталбургское подполье», Evil Bear → «Злой мишка». Название подставляется в готовую фразу без склонения,
  поэтому перед ним в переводе стоит родовое слово в нужном падеже: «в магазине One Stop Shop», «на банду Devil's Angels».
  Сокращения компаний — по буквам кириллицей или по русской расшифровке, если она уже есть в репликах: OS → ОС,
  SOMC → СОМК, SBB → СББ, ARG → АРГ, IC → ИК, SNW → СНВ, TWSC → ТВСК, FDTU → СЛГБ (служба лечения грибковой болезни), SMV → СГВ (Сталбургский грибной вирус);
  LLC и LTD — ООО перед названием: «Swamp Publishing LLC» → ООО «Болото-Пресс». Технические сокращения и марки (USB, DVD, SIM, TV, RNK-68) не меняются.
  Исключения переведены и отмечены на проверку: притяжательные названия («Кебаб и бургер у Азиза»), фильм The Engineer → «Инженер».
- Финские и шведские нарицательные слова (Kilju, Sahti, Kalja, Pontikka, Mämmi, Lonkero, Plörö, Lenkki, Herneviini, Blåbärsvin),
  ругательства и реплики на других языках, пароли (Passed, Passless), клавиши и настоящие названия (Loiste Interactive, INFRA)
  в словари не входят и остаются как в игре.
- Одно латинское написание принадлежит только одной группе (это проверяет `tools/check.py`).

## Навыки

Lockpicking — Взлом замков, Drinking — Выпивка, Cooking — Готовка, Mashing — Браговарение (брага для kilju и самогона, не пивоваренное «затирание»), Brewing — Пивоварение,
Distilling — Дистилляция, Farming — Фермерство, Malting — Соложение, Manufacturing — Производство,
Paperwork — Бумажная работа, Chemistry — Химия, Carpentry — Плотничество, Machining — Станочное дело,
Engineering — Инженерия, Bribery — Подкуп, Cleaning — Чистка, Sewing — Шитьё, Electronics — Электроника,
Mining — Горное дело, Music — Музыка, Smithing — Кузнечное дело, Medical — Медицина, Computers — Компьютеры, Sauna — Сауна.
Уведомление о повышении: «Навык «…» повышен до уровня N!» — название навыка в кавычках, чтобы не согласовывать род.

## Обращения

- Чиновники, интервьюеры, службы поддержки, банк, полиция — на «вы».
- Обычные жители, торговцы, соседи — на «ты», если в оригинале нет подчёркнутой вежливости.
- Журнал заданий, записки, подсказки и системные сообщения — на «вы» (формы «вы нашли» не зависят от пола игрока).
- Crazy Neighbor (мужчина) зовёт игрока «соседушка» — прозвище с мужским родом прилагательных, как обобщённое «сосед».
- Saunaklonkku говорит как Голлум: «мы», «прелесть», растянутое «с-с-с».
- Служебные метки в данных диалогов (DEFAULT, NEW TASK, SEARCH и т.п.) не показываются игроку и оставлены как есть.
- Пол игрока выбирается в начале игры. В репликах игрока и в обращениях к нему избегаются формы прошедшего времени и прилагательные с родом («я готов» → «можно начинать»).
- Lua-вставки, которые возвращают английский текст, в русских полях заменены на функции мода с тем же смыслом:
  `Actor["Player"].AgeName` → `Mod_obenseuerrus_AgeName()` (парень/девчонка, мужик/дамочка, дед/бабуля),
  `Actor["Player"].AgeNameFormalShort` → `Mod_obenseuerrus_AgeNameFormalShort()` (господин/госпожа),
  `Actor["Player"].Pronoun` → `Mod_obenseuerrus_Pronoun()` (он/она),
  прочие английские значения — обёртка `Mod_obenseuerrus_Tr(...)`, которая переводит результат по каталогу.

## Разметка

- Коды пауз Dialogue System `\,` сохраняются в том же количестве и ставятся на естественные паузы русской фразы.
- Lua-вставки `[lua(...)]`, теги `<color=...>`, `<size=...>`, переводы строк — в том же количестве.
- Валюты: OC — КМ, RM — РД (и там, где игра подставляет сокращение сама: запись «OC» в каталоге). Клавиши (E, Tab, Shift…) не переводятся.
- Кнопки меню имеют фиксированную ширину, а машинописный шрифт моноширинный: подпись кнопки не длиннее английской
  (Load Game → «Загрузить», Save Game → «Сохранить», Resume Game → «Продолжить», Apply → «ОК»;
  в столбце меню клавиш — не длиннее 14 знаков: Interact → «Взаимодействие»).
- Один английский текст переводится одинаково во всех местах игры (перевод подставляется по тексту, а не по месту),
  поэтому для коротких слов с разным смыслом заводятся полные строки или шаблоны: «Modifier: Clean», «{0} — Okay».
  Если и это не помогает, строка получает scope: `action` (кнопки действий предмета и подсказка UseText),
  `usetitle` (заголовок объекта в подсказке UseText: «Lock» у автомата — «Фиксация», а не «Запереть»)
  или `object:<родитель>/<объект>` (один объект TextMeshPro: половинки надписи интро «OPEN SEWER», круглая кнопка Drop).
